Heyum — 在3樓遇見海

沿著廣安里海灘的民樂水邊路。推開3樓的窗，海就在一步之外。Heyum 是重視本質而非裝飾的空間。

About Heyum

貼近海灘的樓層， 抵達當天更從容

Heyum 位於3樓。窗外就是廣安里海灘與海面，坐在按摩浴缸裡，廣安大橋正好落在視線高度。從海灘回來放下濕衣服，又能馬上看到海——這段路很短，就是這一層的優點。

約200平方公尺的客廳沿著落地窗展開：沙發、大型坐席桌與餐桌依序相連。孩子在兒童房玩，大人在客廳看海聊天，空間自然分開。

15點入住、11點退房。抵達當天下午多一個小時可用，帶孩子卸好行李再前往海灘也不趕。

    FAQ

    訂 Heyum 前常見問題

    哪一扇窗看得到海？

    客廳落地窗與按摩浴缸一側的窗。客廳可看到廣安里海灘與海面，按摩浴缸還能看到廣安大橋。

    3樓視野會被遮住嗎？

    這是貼近海灘的較低樓層，但窗前沒有遮蔽的建築，海面一覽無遺。想要更高視野，可以選擇6樓 Orot。

    為什麼15點才能入住？

    這段時間用於清潔並為下一組房客準備。15點起客房完全屬於你，抵達當天下午更從容。

    帶孩子入住要注意什麼？

    設有兒童房與嬰兒高腳椅。使用住宿設施時，包括嬰幼兒在內請由監護人負責安全照護。

    有些車型不能停車嗎？

    是的。可使用步行1分鐘的民樂中心·水產市場停車場，1輛免費。訂房時告知車型，我們會確認是否可行。

    如何自助入住？

    預訂確認後，房東會透過預訂對話視窗傳送您的個人數位門鎖密碼。抵達後在大門與房門門鎖輸入密碼即可直接入住，無需經過櫃檯，晚到也很方便。
